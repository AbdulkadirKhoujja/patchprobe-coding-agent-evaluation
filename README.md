# AI Coding-Agent Evaluation: Tenant-Safe Event Deduplication

**Original synthetic demonstration — prepared 27 October 2026.** This is not a client's code, an actual AI agent transcript, or a benchmark score for a real model. The deliberately flawed *candidate* simulates an incorrect AI patch; we do not claim it was generated by an AI assistant.

## Purpose

Reproduce a complete coding-agent evaluation workflow: a realistic engineering task, candidate implementation, executable public and held-out tests, corrected reference implementation, automatic grading, and PR-style evidence.

The application context is an existing event ingestion utility that processes events from several customer workspaces. An implementation that deduplicates `event_id` globally may silently discard another customer's event. Correctness therefore requires tenant-scoped keys, deterministic selection, and fail-closed input validation.

## Run

Requires only Python 3.10+ (standard library; no network, tokens, third-party packages, or environment setup).

```bash
python evaluate.py
```

The script executes public and held-out tests separately against **both** implementations. It writes `evidence/results.json` and `evidence/report.md` with actual test counts. The intentionally flawed candidate should fail specific held-out checks. The corrected reference must pass all tests.

## Contents

- `TASK.md`: agent-facing task and numbered acceptance criteria.
- `candidate/event_inbox.py`: intentionally flawed simulated agent patch.
- `reference/event_inbox.py`: working reference implementation.
- `tests/test_public.py`: tests a coding agent might see.
- `tests/test_holdout.py`: evaluator's independent black-box checks (do **not** give to a real agent until its run ends).
- `REVIEW.md`: concise, evidence-linked PR review and rubric.
- `evaluate.py`: repeatable standard-library test runner and results writer.
